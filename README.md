# 深孔钻产品官网

这是一个可直接部署到 Vercel 的 Next.js 单页官网项目。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://localhost:3000
```

## 部署到 Vercel

1. 把本项目上传到 GitHub。
2. 打开 Vercel，选择 `Add New Project`。
3. 导入这个 GitHub 仓库。
4. Framework Preset 选择 `Next.js`。
5. 点击 Deploy。

## 目录结构

```text
deep-hole-drill-next/
├─ app/
│  ├─ globals.css
│  ├─ layout.jsx
│  └─ page.jsx
├─ public/
│  └─ images/
│     └─ deep-hole-drill-hero.png
├─ .gitignore
├─ next.config.mjs
├─ package.json
└─ README.md
```
